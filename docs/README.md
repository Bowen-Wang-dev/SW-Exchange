## Read Order For Codex / AI

1. Read [ARCHITECTURE_STATE.md](./ARCHITECTURE_STATE.md) first.
2. Read [BUSINESS_RULES.md](./BUSINESS_RULES.md) before touching trading, wallet, transfer, or fee logic.
3. Read [CURRENT_LIMITATIONS.md](./CURRENT_LIMITATIONS.md) before proposing new features.
4. Read [EXCHANGE_BOUNDARY.md](./EXCHANGE_BOUNDARY.md) before describing public product scope.
5. Read [TESTING_RULES.md](./TESTING_RULES.md) before verification.
6. Read [RELEASE_WORKFLOW.md](./RELEASE_WORKFLOW.md) before commit/push work.
